# Фронт: запись тренировки, цели, ПМ (фаза 3, `web/`)

Экраны поверх эндпоинтов из `docs/pwa/workouts.md` и `api-workouts-examples.md`. Стек прежний (Vite, TS, React,
hash-router). Весь новый код в `web/src/screens/record/`, вызовы и типы — `web/src/api/record.ts`, строки —
`web/src/i18n/record.json` (`{ru:{…}, en:{…}}`, ключи `rec.*`, подмешивается в `i18n/index.tsx`).

## Маршруты

| Путь | Экран |
|---|---|
| `#/record` | мастер записи тренировки (`RecordScreen`) |
| `#/w/:uuid` | правка и удаление записанной тренировки (`WorkoutManageScreen`) |
| `#/goals` | «Цели»: к прежнему экрану добавлены добавление цели, завершить/архив, быстрый ввод ПМ |
| `#/` | «Сводка»: виджет `QuickWidgets` (самочувствие 1–10, вес тела, кнопка «Записать тренировку») |
| `#/workouts` | плавающая «+» → `#/record`, блок «Мои записи» (последние ручные тренировки, правка, отмена удаления) |

В нижнюю навигацию вкладку не добавляли (5 вкладок и так плотно на 375 px): вход — «+» на экране «Тренировки» и кнопка
на Сводке. В общих файлах правки минимальные: `App.tsx` (2 маршрута), `Workouts.tsx`, `Summary.tsx`, `Goals.tsx`
(по одной вставке компонента), `i18n/index.tsx` (слияние `record.json`), `api/client.ts` (тело `FormData` для multipart),
`api/types.ts` (`id` у цели и дисциплины).

## Мастер записи (`RecordScreen`)

Шаги: **setup** (день: сегодня/вчера/дата, время начала, вид: Кроссфит/ТА/Hyrox/Бег/Вело) → **board** (только доска-виды)
→ **check** → **result** → **done**. Бег и вело идут setup → result (длительность, дистанция, RPE, вес тела, заметка).
У каждой записи клиентский UUID (`crypto.randomUUID()`, запасной вариант на случай не-secure контекста); несколько тренировок
в день допустимы, «Ещё одна тренировка» выдаёт новый UUID.

- **Доска**: фото (камера `capture` или файл; ≤ 10 МБ и `image/*` проверяются на клиенте, потом `POST /api/uploads`,
  превью), текст, «Программа зала» (`GET /api/gym-program?day=`), «Без доски» (результат свободным текстом).
  Разбор: `POST /api/board/parse` → `{job_id}` → `pollJob` (`lib/jobs.ts`, 1.5 с) → `check`. Движок «Быстро/Точно»
  (`fast`/`slow`). На `check` можно принять, поправить текст и «Разобрать заново» (`verbatim: true`, без ИИ), или «Ещё раз»
  (заново по фото/тексту, другой движок). Принять при неразобранной правке нельзя. Зальная доска — только чтение
  (в PUT уходит `board: {source: 'gym'}`).
- **Результат** (`fields.tsx`): поля по `form.blocks[].fields[]`, группировка по блокам и `group`:
  `weight_reps` — два поля «кг × повт» (вставка «100x5» в поле веса делится сама), `weight` — число или «16/24»,
  `time` — маска мм:сс (`412` → `4:12`, при уходе фокуса нормализуется), `int`, `rounds_reps` — «круги + повторы»,
  `text`. Подсказка «Как вносить результаты» (штанга, гантели, гимнастика, кардио в ladder, for time, AMRAP, scaling).
  RPE 1–10, RX/Scaled, вес тела (20–500).
- **Сохранение**: `PUT /api/workouts/{uuid}`, тело собирает `buildPutBody` (`logic.ts`); повтор безопасен (тот же UUID),
  поэтому после ошибки сети просто «Сохранить» ещё раз.
- **После сохранения** (`FollowUps.tsx`): итог (счёт, метконы), «Новые максы» (`credited`, 1ПМ, уровень `tier`, если пришёл),
  вопросы `ambiguous` («рывок/взятие» → кнопки вариантов → `POST …/lifts/resolve`), `proposed_maxes` (строки с флажком,
  правкой веса/повторов → `POST …/maxes`; ответ может снова содержать `ambiguous`). Ссылки: «Открыть разбор дня»
  (там like-for-like из отчёта дня) и «Править запись».
- **Черновик** (`draft.ts`): весь мастер (шаг, вид, день, значения полей, разобранная доска, UUID, ответ сервера)
  пишется в `localStorage['fepra.record.draft.v1']` на каждое изменение; живёт 3 дня; при открытии показывается
  «Восстановил черновик» и «Начать заново». Очищается по «Готово» и «Ещё одна тренировка».
- **Ошибки** (`errors.ts`): нет сети → «Введённое сохранено на телефоне, повтори»; 429/квота (в том числе `reason:
  quota|no_vision` в job) → предложение ввести текст доски; `not_recognized` → ввести вручную или «Без доски»; 422/400 →
  сообщение сервера; таймаут поллинга; 403 с пояснением.

## Правка и удаление (`WorkoutManageScreen`, `#/w/:uuid`)

`GET /api/workouts/{uuid}` → те же поля формы, что при записи (значения из `form_values`), RPE, RX/Scaled, вес тела.
`PATCH` отправляет только изменённое (`buildPatch`): `rpe`, `scaling`, `bodyweight`, `form_result`, `board {text}`.
Доска правится, только если `board_editable` (=`board_source == 'own'`); иначе поле выключено с пояснением. Если правится
доска, `form_result` в этом же PATCH не шлётся (форма поменяется, значения вводятся заново). Запись с часов
(`editable=false`) открывается только на чтение. Удаление: подтверждение → `DELETE`; экран «Удалено» с «Отменить»
(`POST …/restore`); удалённые за сессию также лежат в `sessionStorage` и показываются с «Отменить» в «Мои записи».

## Цели, ПМ, вес тела, самочувствие

- `GoalsManage.tsx`: «Добавить цель» (числовая: дисциплина + значение в единицах дисциплины — кг, мм:сс или круги;
  уровневая: дисциплина + уровень), у каждой цели «Завершить» и «В архив»
  (`/api/goals/items…`), «Быстрый ввод ПМ» (`POST /api/pm`: лифт — вес×повторы, бенчмарк — время или круги; в ответе
  показываются 1ПМ и уровень). Список дисциплин (`id`, `name`, `kind`, `unit`) берётся из того же `GET /api/goals`.
- `QuickWidgets.tsx` на Сводке: `POST /api/feel` (1–10), `POST /api/bodyweight`.
